# 💧 Neural Water Tracker

An AI-powered Water Tracking application built using Python and Streamlit.

## 🚀 Features

- Daily water intake tracking
- AI hydration recommendations
- SQLite database
- Interactive Streamlit dashboard
- Water consumption history
- Simple and clean UI

---

## 🛠 Tech Stack

- Python
- Streamlit
- SQLite
- Requests
- Logging

---

## ⚙ Installation

```bash
git clone https://github.com/ashutoshmishra7275mishra-create/NEURAL-WATER-TRACKER.git

cd NEURAL-WATER-TRACKER

pip install -r requirements.txt

streamlit run dashboard.py
```
